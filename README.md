Git workflow documentation is maintained through feature branches and Pull Requests.

## Git Workflow

Feature branches are used to develop changes independently from main.

Changes are reviewed and merged into main through Pull Requests.

## Contributing

This repository is a learning project for practicing Git and GitHub workflows.

Contributors can create feature branches and submit Pull Requests to propose changes.

The repository maintainer reviews Pull Requests, checks CI results, and decides whether to merge changes into main.

## Development Workflow

1. Create a feature branch from main.
2. Make changes and commit them.
3. Open a Pull Request.
4. Address review comments and ensure CI checks pass.
5. Merge the Pull Request after approval.
